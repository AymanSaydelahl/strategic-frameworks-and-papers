## English Overview

This repository serves as an official knowledge and documentation index for the strategic crisis, risk, and security frameworks developed and scientifically registered (SSRN / Elsevier) by **Maj. Gen. Ayman Saydelahl**.

### Core Methodologies
1. **[HRDA — High Risk Decision Architecture](./HRDA/README.md)**  
   Cognitive and neurological decision architecture for overcoming acute crisis freezing during the first 60 seconds.
2. **[ISVM — Integrated Security Vision Matrix](./ISVM/README.md)**  
   Proactive vulnerability and gap detection matrix for institutional security alignment.
3. **[A-ORCA — Adaptive Opportunity & Risk Crisis Architecture](./A-ORCA/README.md)**  
   Methodology for managing complex operations, crisis opportunity management, and adaptive resilience.

- **[Policy Papers & Case Studies](./policy-papers/README.md)** — Index of crisis case studies, facility hardening frameworks, and policy papers.
